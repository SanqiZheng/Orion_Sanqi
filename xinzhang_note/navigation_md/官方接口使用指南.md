## 📊 增强功能说明

### 1. 自动资源监控

脚本会自动监控：
- **CPU内存**：使用率、可用量
- **GPU显存**：使用量、温度、利用率
- **Python进程**：内存占用

**监控频率：** 每 5 秒

### 2. 自动保护机制

**内存保护：**
```
内存使用 < 80%  ✅ 正常
内存使用 > 80%  ⚠️  警告（记录到日志）
内存使用 > 90%  🛑 自动终止训练（防止死机）
可用内存 < 1GB  🛑 自动终止训练
```

**GPU保护：**
- 自动清理残留进程
- 显存分配优化
- 温度监控

### 3. 详细日志

**日志位置：**
```
work_dirs/<config_name>/logs/
├── train.时间戳              # 训练主日志
├── resource_monitor.log      # 资源监控详情
├── warnings.log              # 警告汇总
└── final_system_state.log    # 退出时状态快照
```

**日志内容：**
- `train.时间戳`: 完整训练输出
- `resource_monitor.log`: 每5秒的资源使用详情
- `warnings.log`: 所有内存/显存警告
- `final_system_state.log`: 退出时的完整系统状态

### 4. 自动清理

脚本退出时（正常/异常/中断）自动：
- 终止训练进程
- 清理GPU进程
- 保存系统状态
- 显示日志位置

## 🚨 问题排查

### 问题 1: 训练立即终止

**查看警告日志：**
```bash
cat work_dirs/*/logs/warnings.log
```

**常见原因：**
- 初始内存就很高（>80%）
- 数据加载占用过多

**解决方案：**
```bash
# 运行准备脚本
sudo bash adzoo/orion/prepare_system.sh

# 进一步减少样本数
# 编辑配置文件中的 limit_samples
```

### 问题 2: 内存/显存不足

**查看最终状态：**
```bash
cat work_dirs/*/logs/final_system_state.log
```

**解决方案：**
- 减少 `limit_samples`
- 减少 `num_iters_per_epoch`
- 增加系统 Swap 空间

### 问题 3: 找不到数据

**检查数据文件：**
```bash
ls -lh data/infos/b2d_infos_train.pkl
ls -lh data/infos/b2d_infos_val.pkl
ls -lh data/bench2drive/
```

**参考官方文档准备数据：**
- https://github.com/Thinklab-SJTU/Bench2DriveZoo

### 问题 4: 配置文件错误

**查看训练日志开头：**
```bash
head -n 50 work_dirs/*/logs/train.*
```

**常见错误：**
- 缺少 pipeline 定义
- 模型配置不完整

**解决：** 参考 `orion_debug.py` 中的完整配置

## 🎓 理解训练流程

### 训练过程分解

```
启动 → 环境检查 → 数据加载 → 模型初始化 → 训练循环 → 保存检查点
  ↓       ↓          ↓          ↓            ↓           ↓
 OK?   内存OK?   <10GB?    <15GB?      监控中      完成!
```

### 内存使用时间线

```
时间点          操作                内存占用
------------------------------------------------------
启动时          基础系统            2-4GB
+10s           加载数据            +2-4GB (最小化) / +10-20GB (完整)
+30s           初始化模型          +4-6GB
+1min          训练开始            +2-4GB
训练中          稳定状态            维持或缓慢增长
```

### 关键点

- **数据加载**是内存占用大头
- **limit_samples** 参数最重要
- **workers_per_gpu=0** 避免多进程开销
- **with_cp=True** 节省显存
