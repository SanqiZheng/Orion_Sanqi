## ⚠️ 内存保护机制

脚本会**每5秒**检查内存：

```bash
内存使用 < 80%  ✅ 正常
内存使用 > 80%  ⚠️  警告
内存使用 > 90%  🛑 自动终止训练（防止死机！）
可用内存 < 1GB  🛑 自动终止训练
```

**如果看到这样的提示：**
```
⚠️ [时间] 警告：内存使用率 85%
🚨 [时间] 严重警告：内存使用率 92% > 90%
🛑 [时间] 内存压力过大，主动终止训练
```

说明保护机制生效了，**避免了死机**！
