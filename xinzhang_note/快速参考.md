## ⚡ 快速排错

### 立即终止
```
→ 查看 warnings.log
→ 初始内存就>80%
→ 运行 prepare_system.sh
```

### 内存不足
```
→ 减少 limit_samples
→ 增加 Swap 空间
→ 关闭其他程序
```

### 找不到数据
```
→ ls data/infos/*.pkl
→ 检查数据准备
→ 参考官方文档
```

### GPU错误
```
→ nvidia-smi
→ 清理GPU进程
→ 重启系统
```

## 📈 逐步增加

```python
# 第1次：验证流程
limit_samples=5, num_iters=3
观察: resource_monitor.log

# 第2次：小规模
limit_samples=10, num_iters=10
确保: 内存<75%

# 第3次：中等规模
limit_samples=20, num_iters=20
持续监控

# 第4次：完整训练
移除 limit_samples 限制
```

## 💡 关键技巧

1. **数据量是关键** - `limit_samples` 参数最重要
2. **先小后大** - 逐步增加，观察资源
3. **监控为主** - 实时查看 warnings.log
4. **保存成功配置** - 记录能运行的参数
5. **不要用sudo** - 普通权限更安全
