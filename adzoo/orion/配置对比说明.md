# ORION 配置对比说明

## 📋 配置文件对比总览

| 配置文件 | 用途 | LLM | VQA | 显存需求 | 状态 | 适用场景 |
|---------|------|-----|-----|---------|------|---------|
| `orion_stage1_train_minimal.py` | **训练** | ❌ | ❌ | 8-10GB | ✅ 可用 | 流程测试、调试训练 |
| `orion_stage3_infer_light.py` | **推理** | ❌ | ❌ | 7-10GB | ✅ 验证成功 | 不带LLM的轻量推理 ⭐推荐 |
| `orion_stage3_infer_llm_vqa_light.py` | **推理** | ✅ | ✅ | 18-20GB | ⚠️ 需24GB+卡 | 带LLM推理（需大显存） |
| `orion_stage3_infer.py` | **推理** | ✅ | ✅ | 20-24GB | - | 多GPU服务器 |

## 🔍 详细对比

### 1. orion_stage1_train_minimal.py（训练-轻量）

**设计目的**: 在资源受限环境下测试训练流程

**关键配置**:
```python
# LLM配置
tokenizer = None          # ❌ 禁用LLM
lm_head = None            # ❌ 禁用LLM head
use_gen_token = False     # ❌ 禁用生成token

# 数据配置
num_gpus = 1
batch_size = 1
num_iters_per_epoch = 3   # 仅3个iter测试
num_epochs = 1
limit_samples = 8         # 仅8个训练样本

# 优化配置
freeze_backbone = True    # 冻结骨干网络
with_cp = True            # 梯度检查点
fp16 = dict(loss_scale='dynamic')
```

**资源占用**（实测）:
- 显存: 7-10GB
- 内存: 12-15GB
- 训练时间: ~30秒（3 iter）

**优点**:
- ✅ 资源占用最低
- ✅ 快速验证流程
- ✅ 不会死机

**缺点**:
- ❌ 无LLM功能
- ❌ 无VQA功能
- ❌ 不适合真实评估

---

### 2. orion_stage3_infer.py（推理-完整）

**设计目的**: 完整功能的推理评估（原始配置）

**关键配置**:
```python
# LLM配置
tokenizer = 'ckpts/pretrain_qformer/'  # ✅ 启用LLM
lm_head = 'ckpts/pretrain_qformer/'    # ✅ 启用LLM head
use_gen_token = True                    # ✅ 启用生成token

# 数据配置
num_gpus = 32             # 多GPU设计
batch_size = 4            # 较大batch
workers_per_gpu = 4       # 多数据加载进程

# 优化配置
with_cp = True
flash_attn = True
# 未指定fp16（可能使用fp32）
```

**资源占用**（预估）:
- 显存: 18-24GB（每GPU）
- 内存: 30-40GB
- 适合多卡服务器

**优点**:
- ✅ 完整功能
- ✅ 高性能推理
- ✅ 适合论文评估

**缺点**:
- ❌ 资源需求高
- ❌ 单16GB卡可能OOM
- ❌ 32GB内存可能不够

### 3. orion_stage3_infer_light.py（推理-轻量，不带LLM）⭐新增

**设计目的**: 在资源受限环境下进行推理，不需要LLM和VQA功能

**关键配置**:
```python
# LLM配置
tokenizer = None              # ❌ 禁用LLM
lm_head = None                # ❌ 禁用LLM head
use_gen_token = False         # ❌ 禁用生成token

# 数据配置
num_gpus = 1                  # 单GPU优化
batch_size = 1                # 最小batch
workers_per_gpu = 2           # 减少worker

# 优化配置
with_cp = True                # 梯度检查点
flash_attn = True             # Flash Attention
fp16 = dict(loss_scale='dynamic')  # 混合精度
```

**资源占用**（预估）:
- 显存: 7-10GB
- 内存: 12-15GB
- 适合单16GB卡

**优点**:
- ✅ 资源占用低
- ✅ 适合消费级GPU
- ✅ 推理速度快
- ✅ 包含完整的检测和规划功能

**缺点**:
- ❌ 无LLM功能
- ❌ 无VQA功能

### 4. orion_stage3_infer_llm_vqa_light.py（推理-完整轻量）⭐推荐

**设计目的**: 在资源受限环境下进行完整功能推理（包含LLM和VQA）

**关键配置**:
```python
# LLM配置
tokenizer = 'ckpts/pretrain_qformer/'  # ✅ 启用LLM
lm_head = 'ckpts/pretrain_qformer/'    # ✅ 启用LLM head
use_gen_token = True                    # ✅ 启用生成token

# 数据配置
num_gpus = 1              # 单GPU优化
batch_size = 1            # 最小batch
workers_per_gpu = 2       # 减少worker

# 优化配置
freeze_backbone = False   # 不冻结（推理不需要）
with_cp = True            # 梯度检查点
flash_attn = True         # Flash Attention
fp16 = dict(loss_scale='dynamic')  # 混合精度
```

**资源占用**（预估，基于训练经验）:
- 显存: 12-14GB
- 内存: 20-25GB
- 适合单16GB卡

**优点**:
- ✅ 完整LLM和VQA功能
- ✅ 优化资源占用
- ✅ 适合消费级GPU
- ✅ 带资源监控保护

**缺点**:
- ⚠️ 推理速度较慢（batch=1）
- ⚠️ 仍需较多资源

## 🎯 使用建议

### 场景1: 流程测试和调试
**推荐配置**: `orion_stage1_train_minimal.py`

```bash
# 训练流程测试
bash adzoo/orion/orion_dist_train.sh \
    adzoo/orion/configs/orion_stage1_train_minimal.py \
    1
```

**适用情况**:
- ✅ 新手学习代码结构
- ✅ 测试环境配置
- ✅ 调试数据管道
- ✅ 资源严重受限（<16GB显存）

### 场景2: 完整功能推理（有充足资源）
**推荐配置**: `orion_stage3_infer.py`

```bash
# 多GPU推理（需要大显存）
bash adzoo/orion/orion_dist_eval.sh \
    adzoo/orion/configs/orion_stage3_infer.py \
    ckpts/model.pth \
    8
```

**适用情况**:
- ✅ 服务器环境（多GPU）
- ✅ 论文评估结果
- ✅ 性能基准测试

### 场景3: 完整功能推理（资源受限）⭐推荐
**推荐配置**: `orion_stage3_infer_llm_vqa_light.py`

```bash
# 单GPU推理（带LLM和VQA）
bash adzoo/orion/orion_dist_eval_llm.sh \
    adzoo/orion/configs/orion_stage3_infer_llm_vqa_light.py \
    ckpts/model.pth \
    1

# 或使用快速启动脚本
bash adzoo/orion/quick_eval_llm.sh
```

**适用情况**:
- ✅ 消费级GPU（16GB显存）
- ✅ 需要LLM和VQA功能
- ✅ 单机环境
- ✅ 需要资源保护

## 🔧 配置修改建议

### 进一步降低资源占用

如果 `orion_stage3_infer_llm_vqa_light.py` 仍然OOM，可以尝试：

```python
# 1. 减少样本数量（快速测试）
data = dict(
    test=dict(
        limit_samples=10,  # 只推理10个样本
    )
)

# 2. 降低图像分辨率
ida_aug_conf = {
    "final_dim": (160, 320),  # 减半（原320x640）
}

# 3. 减少查询数量
pts_bbox_head = dict(
    num_query=300,       # 减半（原600）
    topk_proposals=150,  # 减半（原300）
)
```

### 提升推理速度

如果有更多显存，可以增加batch_size：

```python
# 修改配置
num_gpus = 1
batch_size = 2  # 从1增加到2（需要额外2-3GB显存）
```

## 📝 快速参考

### 命令速查

```bash
# ========== 训练 ==========
# 训练（不带LLM）
bash adzoo/orion/orion_dist_train.sh \
    adzoo/orion/configs/orion_stage1_train_minimal.py 1

# ========== 推理 ==========
# 推理（带LLM和VQA）⭐推荐
bash adzoo/orion/orion_dist_eval_llm.sh \
    adzoo/orion/configs/orion_stage3_infer_llm_vqa_light.py \
    ckpts/model.pth 1

# 推理（不带LLM，轻量）⭐推荐
bash adzoo/orion/orion_dist_eval_llm.sh \
    adzoo/orion/configs/orion_stage3_infer_light.py \
    ckpts/model.pth 1

# 快速推理（交互式）⭐最简单
bash adzoo/orion/quick_eval_llm.sh
```

### ⚠️ 重要提醒

**不要用训练配置做推理！**

```bash
# ❌ 错误：使用训练配置推理
bash orion_dist_eval.sh \
    configs/orion_stage1_train_minimal.py \  # 这是训练配置！
    ckpts/model.pth 1

# ✅ 正确：使用推理配置
bash orion_dist_eval_llm.sh \
    configs/orion_stage3_infer_light.py \     # 这是推理配置！
    ckpts/model.pth 1
```
